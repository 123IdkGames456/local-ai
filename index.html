Connection & settings

Configure a server that already hosts DeepSeek-V3.2-Speciale and exposes an OpenAI-compatible chat-completions API. This static website cannot deploy or pay for the inference server itself. The model is about 685 billion parameters, and the model page currently says it is not deployed by an Inference Provider. A URL alone cannot make it available; the server must actually have the model loaded.

Paste the full chat-completions endpoint URL. The server must allow requests from this website (CORS).
The key is stored only in this browser's local storage and sent to the server you configure. Do not put a secret key in GitHub code or share this browser profile.
